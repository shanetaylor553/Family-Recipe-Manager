# Family-Recipe-Manager
A small web application that allows my family to store, update, and edit recipes in a database like an online recipe book that we can all share.
# Features
1. Login/Registration
2. Viewing Recipes
3. Adding Recipes
4. Searching Recipes
5. Categories
# Tech Stack
Front-end: HTML, Javascript, CSS, Jinja
Backend: Python
Database: SQLite
